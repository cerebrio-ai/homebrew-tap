# Cerebrio Homebrew Tap

Official [Homebrew](https://brew.sh) tap for Cerebrio CLI tools.

## Install

```bash
brew install cerebrio-ai/tap/cerebrio
```

Works on macOS and on Linux via [linuxbrew](https://docs.brew.sh/Homebrew-on-Linux).

## Formulae

| Formula | Description | Source |
|---------|-------------|--------|
| [`cerebrio`](Formula/cerebrio.rb) | The Cerebrio CLI — agent-native knowledge platform interface | [cerebrio-ai/cerebrio-cli](https://github.com/cerebrio-ai/cerebrio-cli) |

Formulae in this tap are generated automatically by [GoReleaser](https://goreleaser.com) on every CLI release. Do not edit them by hand.
